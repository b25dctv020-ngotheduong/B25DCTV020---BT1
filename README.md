# Bài tập 1: Trang giới thiệu bản thân (CV Cá Nhân)

Đây là mã nguồn cho Bài tập thực hành 1 môn Lập trình Web.

## Thông tin sinh viên
- **Họ và tên:** Ngô Thế Dương
- **Mã sinh viên:** B25DCTV020
- **Ngành:** Trí tuệ nhân tạo vạn vật (AIoT)
- **Trường:** Học viện Công nghệ Bưu chính Viễn thông (PTIT)

## Mô tả dự án
Dự án là một trang web dạng CV cá nhân đơn giản, được xây dựng bằng HTML, CSS và JavaScript thuần để đáp ứng yêu cầu của bài tập thực hành số 1. 

## Các chức năng chính
- **Cấu trúc HTML:** Sử dụng các thẻ ngữ nghĩa cơ bản như `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` (hoặc các thẻ khối kết hợp class) để phân chia bố cục rõ ràng.
- **Giao diện CSS:** Bố cục chia hai cột bằng Flexbox, hiển thị tràn màn hình (100vh) với thiết kế gọn gàng.
- **Thao tác DOM (JavaScript):** 
  - Hiển thị lời chào động (sáng, chiều, tối) sử dụng đối tượng `Date`.
  - Bắt sự kiện `addEventListener` qua nút bấm để thay đổi màu nền của trang một cách ngẫu nhiên hoặc theo mảng màu cho trước.

## Cấu trúc file
- `index.html`: Cấu trúc nội dung của trang CV.
- `style.css`: Định dạng giao diện, màu sắc, font chữ.
- `script.js`: Xử lý logic lời chào và chức năng đổi màu nền.
- `e788eb5b-7122-46da-97f6-51a068d70cc4.jpg`: Ảnh chân dung cá nhân (nằm cùng thư mục).

## Hướng dẫn sử dụng
1. Tải (hoặc clone) toàn bộ mã nguồn về máy tính.
2. Đảm bảo tất cả các file (HTML, CSS, JS, hình ảnh) được đặt trong cùng một thư mục.
3. Mở file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari...) để xem kết quả.
